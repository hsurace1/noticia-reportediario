# noticia-reportediario

Dashboard del clima en HTML/CSS/JS puro, usando la API pública [Open-Meteo](https://open-meteo.com/) (sin API key).

## Funciones
- Búsqueda de ciudad (geocodificación)
- Clima actual: temperatura, sensación, humedad, viento, precipitación
- Pronóstico de 7 días
- Selector °C / °F y recuerda la última ciudad

## Uso
Abrí `index.html` en el navegador, o servilo con `python -m http.server`.
